## 換月份
主程式左下角「資料月份」可以匯入另一個月的 Excel（例如 `AI模擬月份/` 裡的檔案），導入前、月效益、單月回放、班表都會改用那個月；「回到九月」恢復個案資料。

## 重建主程式
```
cd 原始碼
DEMO_HTML=<插單閘門 demo 的 index.html 路徑> python3 build.py dist/sim.html
```
需要 three.js r128（`node_modules/three`）與 `assets/*.glb`。`parts/` 的檔案說明見 `原始碼/README.md`。

## 限制條件
三個月內不加人、不買機台、加班不增加；換線外部化已移出方案。
