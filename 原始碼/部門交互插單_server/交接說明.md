## Demo 怎麼用

1. 用瀏覽器打開 `demo-v2/dist/index.html`。
2. 按右上角橘色「▶ 自動示範」，會自動跑完八個情境（1× 約 3～4 分鐘）：
   1. 老闆收到客戶訊息，轉給官方帳號
   2. 業務在 LINE 確認新單
   3. 生管看試算，決定可交日
   4. 業務回覆客戶，老闆收到可交日
   5. 客戶打電話來下單（網頁備援入口，含 AI 追問缺的數量）
   6. LINE 斷線時
   7. 還沒綁定的帳號
   8. 沒人處理時自動提醒（升級給生管主管）、稽核紀錄
3. 說明卡上可以「暫停／繼續」、調「速度」、「結束示範」（或按 Esc）。
4. 跑完可以「再看一次」，或「關閉」後接著自己點。「重設 Demo」要連按兩次。

開發與測試（在 `demo-v2/`）：

```bash
node build.mjs
npm test
```
